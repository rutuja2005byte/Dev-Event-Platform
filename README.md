# Dev Event Platform

A full-stack event management platform for discovering events.

## Features

- Browse upcoming events
- Create, update, and delete events
- Event detail pages
- Image upload support
- Event registration system
- Similar event recommendations
- Analytics tracking
- Responsive modern UI
- Secure database integration

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend
- Next.js Server Actions
- REST APIs

### Database
- MongoDB
- Mongoose

### Cloud & Services
- Cloudinary
- PostHog Analytics
